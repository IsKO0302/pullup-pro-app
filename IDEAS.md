# IDEAS — deliberately NOT built in v1

Out of scope by the master specification (do not build without a new decision):

- Accounts, backend, sync, social features, leaderboards.
- Notifications / push.
- Nutrition, calorie counting.
- AI chat / coach.
- Subscriptions, ads.
- XP / levels / badges gamification.
- Custom workout builder.
- Exercise video / GIF library.
- Wearables.
- Progress photos and body measurements (planned for v2).
- More than two poster styles; poster formats 1:1 and 16:9.

Ideas that came up while building (parked):
- Pick training weekdays instead of the fixed Monday-first templates (D17).
- Optional "deload now" button when life gets busy (today: Rest today / Make it lighter cover it).
- Share the export file through Web Share (files) on phones, especially iOS Safari, where a blob download is clumsy.
- A custom "Install app" button (`beforeinstallprompt`) in YOU; today the browser's own install UI is used.
- Encrypted export (password) for people who keep backups in cloud folders.
- Automatic local backup to a user-chosen folder (File System Access API, desktop Chromium only).
- Import from a CSV / spreadsheet of past workouts.
